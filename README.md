# McLovin Hotel

### Hotel Booking and Management System with AI-Based Occupancy Forecasting

McLovin Hotel is a full-stack web application built with Laravel, MySQL and Python. It brings hotel reservations, guest records, payments and daily staff operations into one system.

Guests can browse rooms, make booking requests and submit payment details. Staff can manage reservations, verify payments, handle check-ins and departures, and review hotel finances. The dashboard also includes a seven-day occupancy forecast generated by a Python machine learning model.

This application is being developed as a final-year university project.

## Booking Workflow

1. A guest selects a room and stay dates.
2. The application checks room availability and maintenance restrictions.
3. A pending booking is created with an agreed nightly rate.
4. The guest submits payment details and a receipt.
5. Staff review and verify the payment.
6. An authorised staff member confirms the booking.
7. Reception checks the guest in.
8. Staff manage any stay extensions or additional payments.
9. The guest is checked out and the room status is updated.

Booking statuses include:

| Status | Meaning |
|---|---|
| `pending` | Booking request awaiting further processing |
| `confirmed` | Booking approved for the selected stay |
| `checked_in` | Guest has checked in |
| `checked_out` | Guest has completed the stay |
| `cancelled` | Booking has been cancelled |

## Availability and Booking Integrity

The application checks date overlaps before accepting a booking or stay extension.

Two stays overlap when:

```text
existing check-in < requested check-out
AND
existing check-out > requested check-in
```

This allows a room to be booked for a new stay beginning on the previous guest's checkout date.

Booking operations use database transactions and room-level locking. Maintenance restrictions and eligible expired holds are considered during availability checks.

## AI-Based Occupancy Forecasting

The forecasting component uses Python to estimate occupied rooms for the next seven days.

The model uses historical occupancy patterns and features such as:

- Day of the week.
- Month.
- Seasonal date features.
- Previous-day occupancy.
- Previous-week occupancy.
- Recent occupancy averages.

A Random Forest regression model is evaluated using historical forecast windows and compared with a baseline based on the same weekday in the previous week.

The dashboard separates:

- **Confirmed-room counts:** rooms already reserved for each date.
- **Predicted occupancy:** the model's estimate based on historical patterns.

### Training Data

The development database contains synthetic historical stays created for university project development and evaluation.

Results obtained from this dataset demonstrate the forecasting workflow. They do not establish accuracy for a real hotel's operations.

Using the system in a real hotel would require complete historical records, verified room capacity and further evaluation with real operational data.

## Local Installation

### Requirements

Install:

- Git.
- PHP and the extensions required by `composer.json`.
- Composer.
- MySQL.
- Node.js and npm.
- Python with virtual environment support.

Laravel Herd can be used for the local PHP development environment on Windows.

Use the dependency versions recorded in the repository's lock files where available.

### 1. Clone the Repository

```bash
git clone https://github.com/eqramul00/projectResort.git
cd projectResort
```

The repository retains its original name, `projectResort`, while the application is branded as McLovin Hotel.

### 2. Install PHP Dependencies

```bash
composer install
```

### 3. Create the Environment File

In PowerShell:

```powershell
Copy-Item .env.example .env
```

On macOS or Linux:

```bash
cp .env.example .env
```

Generate the application key:

```bash
php artisan key:generate
```

### 4. Configure MySQL

Create a MySQL database, then update `.env` with your local settings:

```dotenv
APP_NAME="McLovin Hotel"
APP_ENV=local
APP_DEBUG=true
APP_URL=http://localhost:8000

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=hotel_management
DB_USERNAME=your_database_user
DB_PASSWORD=your_database_password
```

Replace the example database credentials with your own.

### 5. Run Database Migrations

```bash
php artisan migrate
```

This creates the application's database tables. It does not automatically create a staff login account unless account creation is explicitly provided by the project's seeders.

Do not use `migrate:fresh` on a database containing records you want to keep.

### 6. Configure Public Storage

```bash
php artisan storage:link
```

This makes files stored on the public disk accessible through the application's storage link.

### 7. Install Frontend Dependencies

```bash
npm install
npm run build
```

During frontend development, use:

```bash
npm run dev
```

### 8. Set Up Python

On Windows PowerShell:

```powershell
python -m venv .venv

.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install pandas numpy scikit-learn
```

On macOS or Linux:

```bash
python3 -m venv .venv

.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install pandas numpy scikit-learn
```

The forecasting integration must point to the Python executable available in your environment. Check the forecasting controller before running it on a different operating system.

### 9. Configure Email

Set the mail configuration in `.env` using the credentials supplied by your email provider.

Example:

```dotenv
MAIL_MAILER=smtp
MAIL_HOST=your_smtp_host
MAIL_PORT=587
MAIL_USERNAME=your_smtp_username
MAIL_PASSWORD=your_smtp_password
MAIL_FROM_ADDRESS=bookings@example.com
MAIL_FROM_NAME="${APP_NAME}"
```

Configure transport security according to your provider and the application's `config/mail.php`.

After changing `.env`, clear the configuration cache:

```bash
php artisan config:clear
```

Booking receipt emails are sent synchronously in the current implementation. Sending them does not require a continuously running queue worker, although the request may take longer while the email is sent.

### 10. Start the Application

```bash
php artisan serve
```

Open:

```text
http://localhost:8000
```

If using Laravel Herd, open the local domain assigned to the project instead.

## Project Purpose

This project explores how a web application can support hotel operations while giving guests a clear booking experience.

It combines practical hotel management features with an occupancy forecasting component. The aim is to reduce repetitive administration, organise hotel records and demonstrate how historical booking data can support planning.
